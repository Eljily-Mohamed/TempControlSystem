# IHM

L'interface graphique ci-dessous permet de superviser et de contrôler le système de régulation de température basé sur un élément chauffant. Elle offre une vue d'ensemble sur les mesures de température, la puissance appliquée et les paramètres de régulation en temps réel.

## Fonctionnalités principales :

- **Point de Consigne de Température** : Permet de définir la température cible en °C.
- **Mesures affichées** :
  - **Tension (V)** : La tension mesurée.
  - **Duty Cycle (%)** : Le pourcentage du signal PWM utilisé pour contrôler la puissance.
  - **Courant (A)** : Le courant mesuré.
- **Graphiques** :
  - **Température au fil du temps** : Suivi de la température du système.
  - **Variation de puissance** : Suivi de la puissance envoyée à l'élément chauffant.

## Contrôle de l'acquisition :
Un bouton **"Démarrer l'acquisition"** permet de commencer la collecte et l'affichage des données en temps réel.
