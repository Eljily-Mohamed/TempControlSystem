# Conclusion

## Comparaison expérimentale et finale

Nous avons étudié le chauffage et le refroidissement du système, d'abord de manière théorique, puis expérimentalement, afin de calibrer notre code STM32 et de tester le système final.
Nous avons constaté que les conditions extérieures, telles que la température ambiante, influencent significativement les mesures, entraînant des variations d’un jour à l’autre.
Cependant, en analysant le système dans différentes conditions, nous avons développé une solution plus fiable et modulable.
