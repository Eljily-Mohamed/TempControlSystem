# Documentation du Projet avec MkDocs

Ce projet utilise **MkDocs** pour créer et héberger une documentation structurée.

## Prérequis

Assurez-vous d'avoir installé **Python** (>=3.6) et **pip** (le gestionnaire de paquets Python).

2. Installez les dépendances nécessaires :

   ```bash
   pip install -r requirements.txt
   ```

---

## Lancer la documentation en local

Pour visualiser votre documentation en local, exécutez la commande suivante :

```bash
mkdocs serve
```

Cela démarre un serveur local. Ouvrez votre navigateur et accédez à :

```
http://127.0.0.1:8000/
```

Les modifications apportées aux fichiers seront automatiquement rechargées.
